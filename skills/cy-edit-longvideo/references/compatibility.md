# 剪映导入记录

## 2.6.0 多剪口与标题备选

2.6.0 在 macOS 剪映专业版 11.7 导入了 1920×1080 和 1080×1920 两条多剪口样片。项目帧率为 30000/1001，按 30 fps 导出后各有 3,906 帧。逐帧检查中，进度条出现后没有整条消失，最后一帧均填满。横屏位于顶部，竖屏位于底部。

macOS 剪映专业版 11.7 导入工程后，备选标题在时间线上显示为停用文字片段。右键选择「启用片段」后，文字出现在画面中。实际修改文字并重新打开了草稿，修改已保留。

## 早期版本的 25 帧样片

macOS，剪映专业版 11.7，同一个 FCPXML 包含两条 130 秒合成工程（1080×1920 与 1920×1080，25fps）。

- 导入出现两个可选草稿，并分别保存；多项目单文件路线可用。
- 横竖版的顶部内容标题、中央封面标题参考、白字阴影字幕及底部章节/填充条出现。
- 竖版 60 秒、89 秒观察到不同填充长度，封面已退出，跨主轨剪口仍有标题。
- 横版 60 秒附近播放时底部填充继续前进。
- 竖版实际把一条字幕改成“字幕可编辑核验”，关闭重开后仍可见修改，证实不是图片文字。
- 文件通过 FCPXML 1.10 DTD 检查。
