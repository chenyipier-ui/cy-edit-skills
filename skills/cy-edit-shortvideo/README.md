# 单主题口播精剪

版本：2.3.0 · 公开测试版。作者：CY。

同一个人围绕单一主题录制的一条或多条素材，默认保留原话、原速和原顺序，处理重复、重录、口癖和多余停顿。

由支持 Skills、可访问本地素材和执行脚本的 Agent 按 SKILL.md 运行。交付目录只有一个 FCPXML；字幕、内容标题、开头 5 秒封面参考可编辑，超过两分钟带底部填充条。多条结果在文件内保留独立项目。内部复查、试听与反馈另存。保留原片及工程引用的工作目录资源。

不添加配乐、音效、转场或花式包装。导入剪映后继续审片、修改和最终交付。两套 Skill 共用经验库，长期偏好可更新或撤销。
