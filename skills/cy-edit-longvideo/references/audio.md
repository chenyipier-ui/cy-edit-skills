# 声音与剪口

原片抽取 16kHz 单声道 PCM，按音轨与视频原点对齐。声音地图按 10ms 计算能量；可靠低能量区且不覆盖词才自动压停顿。没有可靠动态范围就保留原范围、列待听。

默认超过 0.6 秒的多余停顿，保留前尾约 0.2 秒与后头约 0.15 秒。情绪、回应、思考停顿用 keep_pause_units 保护。句间没有 ASR 文字不等于没人说话；短促发声也可能是正常应答，不自动当咳嗽或半个字删掉。

剪点限制在已选原文与未选邻句之间；约 0.15 秒内选择词外低能量点，余量不能进入删掉的话。段内删除写候选 cuts，使用真实词边界或已核实区间；不平分多字词时间。

咳嗽、清嗓、卡痰、尾音、密集口癖由声音提示定位后实际回听，删已确认的冗余部分。口癖密度按 10 秒窗口提示，正常指代、数量词、强调、情绪回应保留。

build 按实际切点拼试听，再对成片音频分块转写，比较保留文字与识别差异，列剩余停顿和短促声。不是重新读取原片转写冒充复查。读 [成片复查](review-and-delivery.md) 后登记实际结论；自动测量与听审分别记录。
