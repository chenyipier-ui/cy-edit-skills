# 常见卡点

| 情况 | 下一步 |
| --- | --- |
| 原文编号不存在 | 使用本次最终审阅包，不能沿用变更前的 ID |
| 范围带入未列出的原话 | 收窄范围或补读该句后明确保留，不能只补一个假开关 |
| cut 切入词内 | 用真实词起止或重新精细转写；不平均分字 |
| SRT 没有词级时间 | 整句删留；需要段内剪先补转写 |
| 多个素材帧率不同 | 原片按秒定位、各自资源帧率；不要直接报不能拼 |
| 章节 start 不存在 | 章节必须指向当前最终保留段；删除段以后同时更新章节 |
| 反馈保存失败 | 保留本轮输入重试；未返回 feedback_saved:true 不说全部保存 |
| 重复疑点未处理 | 通读全文，逐对写 keep/revise 及理由；不是全填保留 |
| ASR 复查失败 | 工程可保留待审，不能写已完成声音复查 |
| 交付目录有其他文件 | 使用新的空版本目录，不自动删用户文件 |

只调用当前主流程命令。历史底层 compile-fcpxml/compile-batch 用于兼容旧计划，会产出旧格式文件组，不作为本版单文件交付入口。
