# 素材与时间

接收一个或多个视频，主体为同一人、同一主题。目录按文件名登记；原文件只读。转写分块、审阅包分份；文件数量不代表主题数量。

默认直接引用原片。项目时间线采用第一条素材帧率；各素材保留自身帧率，按秒定位，不用 VFR 的帧序号推时间。混合帧率不强制转码。导入出现同步或方向问题才针对具体素材生成派生副本，说明资源成本后执行。

画布默认为第一条素材尺寸。手机旋转标记、HDR、VFR 和多音轨需要在实际编辑器核对。多音轨材料不能把非人物声的默认轨当成正确配音；发现主声不在默认轨时说明并切换可核实的音轨或交给长内容版的音轨选择。

同名 SRT 可作为原片时间稿导入，只有句级时间时不能精细删半句。源文件改变时重建对应转写、声音地图和阅读包；旧计划先核对，不静默套用。

原片、派生素材、转写、计划、包装素材和反馈保留；试听与分析缓存可在工程验收后按本项目范围清理。FCPXML 引用的文件不能删。
