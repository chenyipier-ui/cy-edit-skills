# 字幕、标题与章节进度条

字幕、标题和每个章节名都是可编辑的 FCPXML 文字。进度条的底色、格线和填充线单独引用工作目录里的图片。

| 元素 | 竖版（9:16） | 横版（16:9） | 时序与写法 |
| --- | --- | --- | --- |
| 字幕 | 中心在画面约 72% 高处 | 约 85% 高处，字高约为画面高的 5% | 白字、黑阴影、单行；按真实词边界拆分 |
| 内容标题 | 顶部居中，约 17% 高处 | **左上角**，左边距 4.5% 画宽，有进度条时避开顶部章节区 | 两行，整条常驻；直说主题和结论，不卖关子 |
| 封面标题参考 | 画面中央 | 中线略偏下（避开上三分之一的人脸），小标签在其下方 | 两行，只显示前 5 秒；标“封面标题参考” |
| 进度条 | 贴画面最底部，1080×1920 时高 44px | 贴画面最上方，1920×1080 时高 44px，章节字默认 28px | 超过 2 分钟才加；从首个章节起点出现并连续填满 |

字号换算（剪映 11.7 实测）：屏幕上一个汉字宽 ≈ `fontSize × 画布高 / 1080`。同一个 fontSize 在竖版上比横版大 1.78 倍，所以版式模块按“占画面短边的比例”设计、再换算回 fontSize，3:4、1:1、4:3、4K 都自动适配，不要手改单个数字。接近方形（宽高比小于 1.5）的横向画面把内容标题改为顶部居中。字数上限也按画宽自动算：16:9 字幕 24 字、标题每行 16 字、封面每行 14 字。

字幕默认竖版（9:16）最多 13 字、横版（16:9）24 字，其他画幅按画宽自动算。词本身超长或只有整句时间时保留可靠时间，不平均分配逐字剪点；报告超长字幕以便核对。去句读，但保留 3.5、1,000、3:1 等有意义的数字符号。转写纠错只改错字，不改说话者实际意思。

内容标题给三组两行文案，直接说出话题与结论。可从主张、方法、适用条件切入，按成片内容选角度。竖版每行建议 12 字以内，横版 16 字以内（左上角标题不宜超过画宽四成）。

封面标题参考给三组两行文案。用成片能兑现的反差、问题或有来源的数字引起兴趣。六组文案各有角度，避免只换标点、断行或语气词。

两类标题各以第一组为默认，第二、第三组分别保留为隐藏的可编辑文字片段。剪映里右键当前文字选择「停用片段」，再右键所选备选选择「启用片段」。在 Final Cut Pro 选中文字片段按 `V` 切换启用状态。[Final Cut Pro 操作说明](https://support.apple.com/guide/final-cut-pro/ver4e2fbd2/mac)

章节按最终文稿划分，章名通常用 2–5 个字。每章占一格，格宽相同。短中文章名适当留字距，长章名按可用宽度缩小，英文单词保留原拼写。格内进度线随这一章的时长推进，进入下一章时到达格线。首章可从开头或钩子之后开始。

`start` 指向保留的剪辑段或原文编号。短视频使用多素材且原文编号相同时，可写 `A:u000001` 指定来源。同一剪辑段内可以有多个章节。

```json
{
  "content_title": [
    ["先理清主线", "再删除重复"],
    ["口播保留推进信息", "剪掉同义复述"],
    ["两句意思一样", "保留表达更完整的一句"]
  ],
  "cover_title": [
    ["剪短一点", "就讲清楚了吗"],
    ["同一句来回讲", "该留下哪一次"],
    ["口播想讲明白", "哪种重复可以删"]
  ],
  "chapters": [{"title": "理主线", "start": "s001"}, {"title": "去重复", "start": "s002"}]
}
```

短视频把这些字段写在计划顶层，长视频写在每个候选内。不超过两分钟可用 `chapters: []`。旧版单组两行计划仍可读取和校验。重新交付时保留原首组，按最终文稿为每类补两组，再用同一交付路径运行 `compile-multi`。最终复查改变内容时，同步改写标题与章节。

## 导入证据的边界

早期版本在本地 macOS 剪映 11.7 的合成验收观察到：原生文字位置、换行、白字阴影、内容标题底色、前段封面、底部位移填充可显示；字幕实际改字后重开仍保留。一个 FCPXML 内两个项目可被识别并分别保存。此结论只覆盖本次写法与环境，不承诺所有字体、剪映版本、Windows 导入器或 FCP 原生样式完全保真。

横竖版布局都是参考版式；长标题、脸部位置与平台遮挡需按实际画面调整，不自动裁脸。其他包装、音乐、音效、转场仍不加入。

[Apple 文字样式说明](https://developer.apple.com/documentation/professional-video-applications/text-style) 与 [位置变换说明](https://developer.apple.com/documentation/professional-video-applications/adjust-transform) 解释 XML 字段；其他软件能保留多少，以导入观察为准。
