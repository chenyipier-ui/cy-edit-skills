# 人物访谈的补充判断

只在内容涉及人物经历或对谈关系时使用。单人课程和一般长口述沿用共同流程，不必进入本文件。

- 经历用于解释现在的判断或行动；联系不清楚时先补足必要原话。
- 把评价与具体事实配在一起，例如选择、行动、结果。不要仅靠人物自我评价撑满一条内容。
- 对谈保住问答前提、同意或反对的真实对象。不同时间和事件的回答不能拼成同一次对话。
- 重复按作用判断。同一词可能分别承担介绍、原因或结论，不机械删光。
- 细节是否保留取决于主题。教程保留必要步骤；人物故事保留能解释选择的细节。
- 开头可以从后文选择，但必须保留前提，并在后文兑现它提出的问题。

发现误听、数字口径、专名、说话人或素材缺口时逐项记录。先回听能澄清的内容；仍不能确认才给用户具体原句和时间。不得代替人物补经历或观点。

内容判断在单条和多条结构中共同使用，不预设固定条数、商业目标或发布位置。
