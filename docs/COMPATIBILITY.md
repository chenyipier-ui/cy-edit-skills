# 环境与工程说明

## 运行环境

- macOS Apple Silicon / Intel，Windows 10/11 x64。
- 能读取本地素材、执行脚本并使用 Skills 的 AI Agent。
- 首次配置需要网络、磁盘空间和用户目录写入权限；后续复用依赖与模型。
- Windows ARM、旧系统和手机端不属于当前适配目标。

FCPXML 生成不需要安装 Final Cut Pro。剪映专业版需有 FCPXML 工程导入能力，具体入口按当前客户端界面操作。Final Cut Pro 可通过“文件 → 导入 → XML”读取 FCPXML，详见 [Apple 导入说明](https://support.apple.com/zh-cn/guide/final-cut-pro/verdbd66ae/mac)。

## 工程格式

交付使用 **FCPXML 1.10**。一个文件可以包含多个独立项目，原素材和生成的资源仍保存在原位置。跨电脑交接时一并转移媒体与项目工作目录，并在目标电脑核对或重链接。

字幕、内容标题和封面参考使用可编辑文字；进度条使用单独资源。画幅布局见 [使用指南](USER_GUIDE.md#六交付内容与版式)。

## 已有导入记录

2026-11-12，macOS 剪映专业版 11.7.0：同一 FCPXML 中的 1920×1080、1080×1920 两个项目分别导入并保存，标题、字幕、封面参考及底部进度条显示；字幕修改后，关闭并重新打开仍保留修改。对应文件通过 FCPXML 1.10 DTD 检查。

## 导入后怎么继续

1. 在剪映专业版通过工程导入入口选择 FCPXML，不要把它当作普通视频拖入素材箱。
2. 多项目时选择对应内容，检查素材链接、画幅与文字位置。
3. 按团队习惯审片、调整字幕和切点、加入配乐与包装，再导出成品。
4. 返修时保留已有剪映草稿与新生成工程，分别命名，便于比较。
