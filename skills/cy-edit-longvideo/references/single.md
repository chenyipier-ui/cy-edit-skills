# 将长内容精简为一条完整作品

读完所有来源后组织一条完整作品，不重复建立另一套转写或分析流程。先明确观众、目的、范围、表达形式；默认保留主要章节及一条总主线，完整不是每个原话题都露一面。只有用户明确要聚焦某个问题时才收窄为单专题，不因时长压力擅自把整体精简变成局部摘录。人工已粗剪则继续结构优化；已确认最终文案则直接定位执行。

1. **初筛。** 标记明确不要、无关支线、重启重复与不可用段，写原因。疑似错听先核对原音，不能因转写不通就删。
2. **归话题。** 把前后分散的同一问题归并，区分复述、补充、主动改口、条件和不同事件。先组织少量可理解的大块。
3. **按目的重排。** 写原顺序与新顺序。可按问题—判断—证据，结果—回溯—选择，使用／服务过程，或标准—行动—关系组织。结构服务素材，不能硬套。
4. **通读精简。** 从新稿开头读到结尾，检查指代、问答、时序、因果、条件、重复、证据与双方作用。先删旁支和冗余论据，再处理口头冗余。
5. **专门选开头。** 回查全片，给一个首选和有意义的备选，解释统领作用及所需前提。开头前置后复读，检查是否重复、是否兑现承诺、结尾是否收住。

组织内容时就思考内容主题和观看价值；完成结构后才最终选定开头。开头让观众理解这条内容要回答什么；过程、经历或论证需要的场景导入应保留，不机械规定前三秒冲突。

## 目的必须有证据

每个希望观众形成的判断，列“原句／行为／经历 → 叙事作用 → 缺口”。例如负责要由具体跟进、纠错、承担结果证明，不能只堆“我们很负责”。内部讲话改为外部成片时，重新判断哪些内容对新观众有用。

对谈若要体现引领、认可、分歧或互相理解，应有双方实际表达支撑。不能只有一个人描述关系，而删除另一方所有证据；也不要求双方时长相等。孤立的“对”“不会”“这件事”须恢复必要前提。

## 压缩与交接

先删无关支线、同义重复、次要例子和长铺垫。必要因果和关键证据不能为了固定分钟数全部削薄；硬上限冲突时给缩小主题等选择。

方案正文给直接可读的精简稿、删留理由和有意义的开头备选；原文位置放附录。这些是内容判断，不要求重复填十几项字段。只知道句级时间就说明精度，不伪造字级剪点。

估时由实际说话速度和所选区间更新，字数仅初估。更短备选写明先删什么、损失什么、不能删什么。长版与短片共存时长版单独建主线和过渡，不把短片直接相接。
