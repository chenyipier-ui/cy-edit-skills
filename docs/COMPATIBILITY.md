# 兼容范围

当前交付入口生成 FCPXML 1.10 工程交换文件。文件需要导入剪映，不能作为剪映原生草稿直接打开。一个文件可包含多个独立项目，原素材及生成的图片资源仍须保留。

## 已有编辑器观察

2026-11-12 的本地开发验收记录：macOS，剪映专业版 **11.7.0**。导入同一个 FCPXML，其中有横版 1920×1080 与竖版 1080×1920 两个项目，均为 25fps、130 秒的合成画面与声音，含两个剪辑段及非零素材入点。

- 两个项目被识别并保存为各自草稿。
- 顶部内容标题、开头 5 秒中央封面参考、白字阴影字幕和底部填充条可见。
- 竖版约 60 秒与 89 秒的填充长度不同；跨主轨切点后标题、字幕仍显示。
- 横版也显示对应布局，播放时填充条前进。
- 在剪映中修改竖版字幕文字，离开并重开项目后修改保留。
- 对应 FCPXML 通过 1.10 DTD 检查。

上述为开发阶段已有观察记录，发布整理没有把它当作重新进行的真人素材听审。当前仓库不附客户素材，也不伪造测试截图。

## 尚未验证

- Windows 实机环境、Windows 剪映导入、GPU 回退。
- macOS 全新用户从零安装完整环境与模型。
- Final Cut Pro 原生应用往返、其他剪映版本、任意字体和标题长度。
- 多音轨、混合帧率、旋转、VFR 等所有组合的编辑器表现。
- 真人口播及访谈的完整内容、漏词、尾音、听感和商业交付验收。

横竖版布局测试不代表任意素材均可自动构图。导入实际项目后，仍需检查字幕、标题、声音、剪口、媒体链接和导出效果。
